# Contributing

1. Branch from `main`, one change per branch.
2. Run `npm run check` before pushing. CI runs the same four checks on every pull request.
3. Open a pull request. A teammate reviews it on GitHub and leaves comments; at least one approval is needed to merge.
4. Review comments that led to a fix are copied by hand into `.improvement-loop/findings.jsonl`, so we can see which mistakes keep coming back.
